# UrnaFácil - Frontend

Página única (`index.html`) que consome a API do backend.

1. Rode o backend: `cd backend && uvicorn main:app --reload --port 8000`
2. Abra `frontend/index.html` no navegador (o campo "Backend da API" já aponta para `http://127.0.0.1:8000`).
3. Clique em "Carregar seções", marque as seções e pesquise pelo número do candidato.
